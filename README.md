# Turf Up

A log for casual football. Record each turf session (ground, 5- or 7-a-side, duration, goals, a note) and see sessions per month, favourite grounds, goals and week streaks. Built for weekend footballers, not gym-goers or runners.

Free, MIT-licensed, no tracking, works offline. Your sessions stay in your browser; export a JSON backup from the Sessions screen.

```bash
pnpm install
pnpm dev
pnpm typecheck && pnpm test && fas check
```

Publish with `fas login` then `fas publish`. See `CLAUDE.md` for repo notes.
